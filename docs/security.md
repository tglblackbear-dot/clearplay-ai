# Segurança e privacidade

- Nenhuma chave administrativa do Supabase no frontend ou na extensão.
- RLS em todas as tabelas de preferências do usuário.
- Mapas públicos contêm apenas metadados necessários para filtragem.
- A extensão solicita apenas permissões declaradas no manifest.
- Nenhum vídeo é baixado, descriptografado ou modificado.
- DRM e fluxos protegidos não são suportados.
- Logs não devem conter e-mails, tokens ou dados de reprodução identificáveis.
- A análise de imagens sensíveis só ocorre com autorização técnica e jurídica.
