# Guia do usuário

1. Instale a extensão no Chrome ou Edge.
2. Abra o app e crie um perfil de filtragem.
3. Inicie uma reprodução em um player compatível.
4. O popup mostrará se um player foi detectado.
5. Ative ou desative a filtragem com um clique.

Ausência de alertas **não** garante ausência de conteúdo sensível. Os mapas dependem de análise, fontes autorizadas e validação.

A extensão não funciona em serviços protegidos por DRM.
